# ゲームUI整理（2026-11-11）

## 今回の変更
- 左上の章名、進行線、目標・装置説明パネルを非表示。空いた縦幅をゲーム描画に戻した。
- 下部の常設操作説明、通常の保存通知、右下の操作状態説明を非表示。保存失敗の警告は残す。
- 会話本文、人物、方向ボタン、調べる・切替、ヒント・休憩は進行を壊さないため残す。
- 宝箱と近くの操作対象をクリック可能にした。遠隔操作・自動移動はしない。既存の近接・謎の条件をそのまま使う。
- ステージ切替のブロッキング会話モーダルは、上中央の約3秒通知に置換。会話は下部に残す。
- 通知はクリックやゲーム操作で消える。通常の続きから、やり直し、人物切替では再表示しない。
- 目標はヒントを開くと確認できる。ヒントの段階は既存どおり。

## 次に本人と決めるもの
各謎の常設表示を一括で決め打ちはしない。歯車の状態、配線ロック、門、足場・かけら、充電率を、実物の表現で十分伝えるか補助UIを置くか順に検討する。非表示にした説明はモデルに保持。

## 検証
単体243件、型・ビルド、内容・配布物検査。ブラウザのクリック、背景誤操作、通知自動終了、再開時非再表示を確認。通常入力による全6謎、全場面通知、PC/小画面、休憩中の停止、帰還・再開を確認（ブラウザ例外0）。実機スマートフォン・Safariは対象外。

## 追加：第1謎の待機と合流
第1謎だけは歩数で門を開ける旧解法を置き換えた。主人公が門の手前へ進むと、追従するトトが z=5 の白い印に乗る。待機ボタンでトトを残すと門が開き、奥の合流レバーで開放固定・トト合流、出口を調べると第2謎へ進む。解除も可能。後半の昔の部屋の歩数／時間ルールは変更しない。

待機状態は既存セーブ形式に任意フィールドとして追加。旧セーブにフィールドがなくても読める。旧第1謎で門の先にいた場合は合流レバーを操作して続行できる。

第1謎の装置をクリックすると、まずレトロ調の説明パネルを開く。近くのレバー／出口だけ実行ボタンを出す。遠くの装置は観察だけで遠隔操作しない。E／調べるボタンも同じ説明経由。床の印と門を線で接続し、門は実際の格子で開閉を表示。待機の有無と門の状態を色だけに依存せず文言で表す。
