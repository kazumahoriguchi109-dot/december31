# 12月31日 エンディング

## 実装した順序
- 最終充電が完了した際に、光・かけらの帰路と「ついた！」「待って。そっちに行くから。」を表示。ここでは自動帰還せず、引き続き二人を出口に移動させる。
- 既存の二人集合・充電完了判定でクリアした後、出口で「今度は、いっしょに。」「うん。帰ろう。」。
- 同一キャラクターの手をつなぐ姿勢と、立体→色→白黒→暗闇の約6秒の逆順演出。スキップ可能。動きを少なくする設定では安定したカラー表示。
- 冒頭と同じ部屋へ帰還し、待機・協力・昔の部屋の意味を回収する会話。
- テレビ内の宝箱が静かに閉じる。実際の画面テクスチャを描画して蓋を閉じる。宝箱の起源など新設定は追加しない。
- 12月31日のまま「今年最後のゲーム」「来年も？」「もちろん。」、終幕。
- タイトルへ戻る／もう一度見る。素材表記は終幕に保持。

## 保存と互換
謎のセーブ形式は変更しない。エンディング位置は別キー `:ending` に保存。再読み込みは現在の台詞から、演出中の再読み込みは演出冒頭から。新規開始はこの位置をリセット。旧クリア済みデータは先頭から鑑賞可能。
