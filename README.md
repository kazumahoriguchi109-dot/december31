# 12月31日

大晦日の昼、ゲームの中へ迷い込んだ幼馴染の二人が、六つの謎を解いて自分たちの部屋へ帰る、戦闘のない脱出アドベンチャー。ブラウザで遊べます（PC・キーボード向けの開発途中版です）。

**遊ぶ：** https://kazumahoriguchi109-dot.github.io/december31/

- 再設計版のセーブは、このブラウザの localStorage に保存されます。旧公開版のIndexedDBとは別で、旧セーブを読み込み・移行・削除しません。今回の再設計版は最初からのプレイになります。端末やブラウザ間での同期はありません。
- 冬景色の3D素材、会話の表情、段階的な画風と操作の変化を実装しています。タイトル画はAI生成。再設計版の音はプロジェクト独自の合成音です。旧実装で使用するKenneyのCC0素材もリポジトリ内に保持しており、出典は第三者通知とassets/audio/SOURCES.mdを参照。

## 操作

- WASD / 矢印キー：歩く
- E / Space：近くの物を調べる・操作する
- Shift：走る（最初の進化後）
- T：仲間に待ってもらう・呼ぶ（最初の進化後）
- Q：視点を回す（奥行きの進化後）
- R：二人の記憶を探す（最後の進化後）
- Esc：一時停止・設定

## 開発

```bash
npm ci
npm run dev        # http://127.0.0.1:5173/
npm test           # 単体テスト
npm run e2e        # ブラウザテスト（Chromium / WebKit / Firefox）
npm run build && npm run check:bundle
```

Node は `.node-version` を参照。GitHub Pages へは `main` への push で `.github/workflows/pages.yml` が自動で公開します。
