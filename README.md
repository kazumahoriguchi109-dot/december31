## 現在の入口：6謎の部屋型試作

白黒の上下移動→色の配線→立体の協力→昔と今の部屋を使い分ける、導入＋6謎を試せます。詳しい判定、座標、保存、未確定事項は [実装仕様](docs/EVOLVING_PUZZLES.md) を参照してください。新保存は `dec31-evolving-puzzles-v1`。以前の試作はタイトルの「前の試作を遊ぶ」から開け、以前の記録は残っています。

- WASD / 矢印キー：1マス歩く（白黒の部屋では上下のみ）
- E / Space / 画面の調べるボタン：近くの装置
- T / 人物切替：操作する相手を選ぶ（第3謎から）
- H / ヒント：観察→原理→具体操作の3段階
- Esc：休憩・設定・今の謎をやり直す
- 立体の視点は部屋ごとに固定。自由回転/走る/精密ジャンプはありません。

新試作は仕組みを確認するマス型の部屋構成です。旧版の広い冬の世界・収集会話をすべて移植した完成版ではありません。スマホの画面ボタンにも対応しますが、初見でのわかりやすさは試遊で確認中です。

### 背景動画の自動再生

再生・停止ボタンや状態ラベルは表示せず、タイトル表示中に無音で自動ループします。最初の自動再生がブラウザに拒否された場合は、次の通常のクリック・タップ・キー操作で再試行します。ネットワーク復帰・タブ再表示でも再試行し、失敗中は既存の静止画を残します。

OSとゲームの動きの軽減設定、対応ブラウザのデータ節約設定は引き続き尊重します。ブラウザがユーザー操作前の再生を禁止している場合、操作なしの再生を保証することはできません。
